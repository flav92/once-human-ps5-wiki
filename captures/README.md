# Captures d'écran — sources du wiki

Ce dossier archive les captures PS5 qui servent de preuve aux données publiées sur le wiki.
Il n'est **pas inclus dans le site publié** : il sert de référence vérifiable.

## 2026-09-10 — Armures (25 captures)

Écran **Schémas → Schémas de protection**, personnage niveau 41, tous les schémas en **Rang V**.

- `capuche-*.jpg` — les onze ensembles vus depuis l'emplacement casque
- `veste-*.jpg` — les onze ensembles vus depuis l'emplacement haut
- `cle-*.jpg` — quatre pièces « Protection clé » (effet unique, pas d'ensemble)

**Ce que ces captures établissent** : les effets d'ensemble sont identiques quel que soit
l'emplacement ; seules les statistiques de base changent (casque 740 PV / 12 pollution / 92 Psi,
haut 1 924 PV / 16 pollution / 64 Psi). Coût de déverrouillage uniforme : 2 000 Protochrome.

## 2026-09-17 — Inscription au nouveau scénario (1 capture)

`popup-nouvelle-inscription-scenario.jpg` — popup en jeu (PS5 FR) :
**« Nouvelle inscription au scénario disponible — Le scénario est entré dans une nouvelle phase.
L'inscription pour le nouveau serveur est disponible. »**, avec les invites `R1` + `✕` Oui / `R1` + `◯` Refuser.

**Ce que cette capture établit** : le libellé FR exact du message, la double validation `R1` +
bouton (sécurité console), et le fait que la popup ne propose aucune option « ne plus afficher » —
elle revient donc à chaque connexion tant que la fenêtre d'inscription est ouverte.
Voir [Inscription au nouveau scénario](../docs/jeu/inscription-nouveau-scenario.md).
