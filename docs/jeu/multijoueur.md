# Multijoueur

*Dernière mise à jour : 20 octobre 2026*

!!! note "Fiabilité et périmètre"

Les relevés en jeu viennent d'un serveur Evolution's Call (septembre 2026). Les règles PvP propres à ce scénario sont sur [PvP et phases de serveur](../scenarios/evolutions-call/multijoueur-pvp.md) ; celles d'un serveur privé comme [RaidZone / Red Zone](../scenarios/raidzone.md) peuvent être différentes.

Quatre opérations distinctes, à ne pas confondre :

| Je veux… | Ce qu'il faut faire |
|---|---|
| Ajouter un ami | Depuis le jeu, avec son identifiant de personnage |
| Entrer sur un serveur plein où joue un ami | Utiliser son **Code d'invitation spéciale** |
| Choisir le serveur | Au moment de créer le personnage |
| Retrouver un ami sur le même serveur | Changer de **monde** pour prendre le même que lui |

## Ajouter un ami

⚠️ L'ajout se fait dans le jeu, pas par la liste d'amis de la console : onglet **Social**, recherche par l'identifiant de personnage Once Human. *À compléter : intitulés exacts du menu sur PS5.*

## Code d'invitation spéciale

- Chaque joueur a un **Code d'invitation spéciale**, visible depuis son profil (« Voir le code d'invitation spéciale »), valable pour **5 invités maximum** ✅ (relevé le 07/09/2026).
- ⚠️ D'après la FAQ officielle du lancement console, ce code sert à **entrer sur un serveur plein** : sans le code d'un ami, un serveur plein reste inaccessible.
- *À compléter : écran où l'invité saisit le code sur PS5, et récompenses de parrainage.*

## Choisir le serveur

- La région et le serveur se choisissent à la création du personnage ; un personnage reste dans sa région. Voir [Serveurs et régions](../ps5/serveurs.md).
- Les serveurs préfixés **« Console »** sont réservés aux joueurs PS5 et Xbox : un ami sur PC ou mobile ne peut pas vous y rejoindre ⚠️.

## Rejoindre un ami sur le même serveur

- Sur un même serveur, deux joueurs peuvent être dans des **mondes** (instances) différents. Allez à une **Tour de téléportation**, choisissez **« Changer de monde »** au lieu de la téléportation normale, puis le même numéro de monde que votre ami 🎮.

## Grouper et partager une base

- **Base commune** : un seul territoire principal par joueur. Pour une grande base à plusieurs, créez une **Ruche**, placez vos territoires côte à côte et partagez les permissions 🎮. La Ruche compte **8 membres maximum** ✅ (Evolution's Call, 10/09/2026) — voir [Factions armées et Ruches](../scenarios/evolutions-call/factions.md#la-ruche).
- *À compléter : inviter un ami dans une équipe (menu et limite de membres sur PS5).*
