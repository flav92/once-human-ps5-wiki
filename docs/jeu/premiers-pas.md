# Premiers pas sur Nalcott

*Dernière mise à jour : 6 septembre 2026*

Once Human est un jeu de **survie multijoueur post-apocalyptique** dans un monde ouvert surnaturel : le continent de Nalcott, contaminé par la Stardust. Les piliers du jeu :

- **Exploration libre** d'un monde ouvert
- **Capture de Déviants** (créatures anormales qui vous assistent en combat, à la base, etc.)
- **Construction de territoire** (votre base, déplaçable)
- **Coopération multijoueur** (jusqu'aux boss de monde en groupe)
- **Scénarios saisonniers** qui renouvellent les règles à chaque saison

Les développeurs annoncent **plus de 300 heures de contenu** disponibles dès le lancement console.

## Lire la carte (retours terrain)

- **Zones noircies sur la carte** : a priori ce sont les **zones irradiées/polluées** (hypothèse terrain à confirmer — prudence en s'y engageant : vérifiez votre équipement de protection).
- Icône **maison verte** = votre territoire ; **maison bleue** = territoire d'un coéquipier ; tracé **jaune pointillé** = itinéraire ; marqueurs **roses/rouges** = éléments ennemis ou dangers.

## Conseils pour bien débuter sur PS5

1. **Réglez la liaison de compte d'abord** si vous venez du PC/mobile → [Liaison de compte](../demarrage/liaison-compte.md).
2. Choisissez un serveur **EU**, et un serveur « Console » si vous voulez du 100 % manette.
3. Suivez la quête principale au début : elle débloque les mécaniques une par une (craft, base, Déviants).
4. Testez la **vue à la première personne** (nouveauté console) pour les phases de tir.
