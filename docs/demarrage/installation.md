# Installation et premier lancement

*Dernière mise à jour : 6 septembre 2026*

## Télécharger le jeu

Once Human est **free-to-play** sur le PlayStation Store : cherchez « Once Human (F2P) » ou passez par la [page officielle du store](https://store.playstation.com/en-us/concept/10015762/).

- **Taille du client : ~80 Go sur PS5** (prévoyez la place, le jeu grossit avec les mises à jour).
- Le téléchargement partiel est supporté : vous pouvez lancer le jeu avant la fin du téléchargement complet.
- **PS Plus n'est PAS requis** pour jouer, même en multijoueur.

## Modèle économique

- Jeu de base entièrement gratuit.
- Contenu payant : **cosmétiques et Battle Pass uniquement** — les développeurs annoncent l'absence de pay-to-win.

## Avant de créer votre personnage

⚠️ **Si vous avez déjà joué sur PC ou mobile, ne créez PAS de personnage tout de suite.** Lisez d'abord la page [Liaison de compte](liaison-compte.md) : lier vos comptes après coup peut vous faire **perdre des personnages**.

## Premier lancement

1. Choisissez votre **région de serveur** (EU pour l'Europe — le crossplay ne fonctionne qu'au sein d'une même région, voir [Serveurs et régions](../ps5/serveurs.md)).
2. Choisissez un serveur : les serveurs préfixés **« Console »** sont réservés aux joueurs console ; les autres sont mixtes PC/mobile/console.
3. Choisissez un **scénario** (saison). *À compléter : liste des scénarios disponibles côté console et recommandations pour débutants.*
